# MOMONet

## 프로젝트 개요

MOMONet은 경동대학교 재학생을 위한 JSP 기반 온라인 중고장터 웹 프로젝트입니다.

전공·교양 교재와 학생 생활에 필요한 상품을 중고로 거래할 수 있도록 하여, 교재 구매 부담을 줄이고 직접적인 친분이 없어도 학교 구성원 간 거래가 가능하도록 돕는 것을 목표로 합니다.

발표 자료 기준으로 MOMONet은 중고나라, 당근마켓, 번개장터와 같은 기존 중고거래 서비스를 참고하여, 경동대학교 재학생이라는 특정 사용자층에 맞춘 교내 중고거래 플랫폼으로 설계되었습니다.

## 개발 배경 및 목적

대학생은 매 학기 전공 교재와 교양 교재를 구매해야 하며, 일부 교재는 가격 부담이 큽니다. 또한 필요한 책이나 물품을 중고로 구하고 싶어도 같은 학교 학생과 연결되는 통로가 부족하면 거래가 어렵습니다.

MOMONet은 이러한 문제를 해결하기 위해 경동대학교 재학생을 대상으로 한 온라인 중고장터를 구현했습니다.

주요 목적은 다음과 같습니다.

- 교재 및 중고 상품 거래 편의성 향상
- 재학생 간 안전하고 간편한 거래 환경 제공
- 상품 검색, 등록, 주문, 찜하기 등 중고거래 기능 구현
- 판매자와 구매자 페이지를 구분한 사용자 흐름 제공

## 주요 기능

### 1. 메인 페이지

메인 페이지에서는 최근 등록된 상품을 확인할 수 있습니다.

검색 바를 통해 사용자가 원하는 상품을 간편하게 검색할 수 있으며, 네비게이션 바 우측 상단에는 라이트 모드와 다크 모드 전환 기능을 제공합니다.

### 2. 회원가입 및 로그인

회원가입은 아이디, 비밀번호, 이메일을 입력하는 방식으로 구성되어 있습니다.

아이디는 학번 7자리 형식을 기준으로 하며, 비밀번호는 6~20자 범위와 영문 및 숫자 조합 조건을 적용합니다.

또한 데이터베이스에 존재하는 학번 7자리를 기준으로 가입 가능 여부를 확인할 수 있도록 설계했습니다.

### 3. 비밀번호 찾기

사용자가 아이디와 이메일을 입력하면, 가입된 정보를 데이터베이스에서 확인한 뒤 임시 비밀번호를 이메일로 전송합니다.

이를 통해 사용자가 비밀번호를 잊어버렸을 때 계정을 복구할 수 있도록 구현했습니다.

### 4. 판매자 페이지

판매자는 상품 사진을 업로드하고, 상품 설명을 입력하여 판매 상품을 등록할 수 있습니다.

상품 등록 과정에서는 사진 업로드와 설명 입력란을 제공하여 구매자가 상품 정보를 확인할 수 있도록 구성했습니다.

### 5. 구매자 페이지

구매자는 등록된 상품의 사진과 정보를 확인한 뒤 구매 의사를 결정할 수 있습니다.

구매 요청 시 원하는 거래 시간과 장소를 입력할 수 있으며, 판매자는 구매자가 작성한 정보를 바탕으로 요청을 수락하거나 거절할 수 있습니다.

### 6. 찜하기 기능

사용자는 관심 있는 상품을 찜할 수 있습니다.

이를 통해 구매하고 싶은 상품을 따로 저장하고 다시 확인할 수 있습니다.

### 7. 페이지 전환 기능

각 페이지의 좌측 하단 버튼 또는 문장을 통해 다른 페이지로 이동할 수 있도록 구성했습니다.

사용자가 회원가입, 로그인, 상품 등록, 주문 등 주요 흐름을 쉽게 이동할 수 있도록 설계했습니다.

## 실행 전 설정

이 저장소에는 보안을 위해 실제 데이터베이스 비밀번호와 Gmail 앱 비밀번호를 포함하지 않았습니다.

`DBUtil.java`와 `MailUtil.java`는 환경 변수를 우선 사용하도록 정리되어 있습니다.

### 데이터베이스 환경 변수

```bash
MOMONET_DB_URL=jdbc:mysql://localhost:3306/momonet?serverTimezone=Asia/Seoul
MOMONET_DB_USER=root
MOMONET_DB_PASSWORD=YOUR_DB_PASSWORD
```

### 메일 전송 환경 변수

```bash
MOMONET_MAIL_HOST=smtp.gmail.com
MOMONET_MAIL_USER=YOUR_EMAIL@gmail.com
MOMONET_MAIL_PASSWORD=YOUR_APP_PASSWORD
```

환경 변수를 사용하지 않을 경우, 로컬 테스트용으로 `DBUtil.java`, `MailUtil.java`의 예시값을 본인 환경에 맞게 수정하여 실행할 수 있습니다. 단, 실제 비밀번호가 들어간 파일은 GitHub에 올리지 않도록 주의해야 합니다.

## 실행 방법

1. Eclipse에서 Dynamic Web Project로 프로젝트를 가져옵니다.
2. Apache Tomcat 서버를 연결합니다.
3. MySQL에 `momonet` 데이터베이스를 생성합니다.
4. `DBUtil.java`의 DB 접속 정보를 본인 환경에 맞게 설정합니다.
5. 필요한 라이브러리가 `WEB-INF/lib`에 포함되어 있는지 확인합니다.
6. Tomcat 서버에서 프로젝트를 실행합니다.
7. 브라우저에서 메인 페이지에 접속하여 기능을 확인합니다.
